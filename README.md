# Task Tracker CLI

Консольное приложение на Java для управления задачами. Данные задач сохраняются в файл `tasks.json`, поэтому они остаются доступными после перезапуска приложения.

## О проекте

Task Tracker CLI помогает управлять задачами из терминала.

Основные возможности:

- создание задачи;
- просмотр одной задачи по ID или списка всех задач;
- изменение названия, приоритета, статуса и срока выполнения;
- удаление задачи;
- фильтрация задач по приоритету, статусу и сроку выполнения;
- сохранение задач в формате JSON.

У каждой задачи есть ID, название, приоритет, статус, дата создания и срок выполнения.

Доступные приоритеты:

- `low`
- `medium`
- `high`

Доступные статусы:

- `to-do`
- `in progress`
- `completed`

При создании задачи без указанного приоритета устанавливается `low`, без статуса устанавливается `to-do`, а без срока выполнения задаётся дата через 10 дней. Даты вводятся в формате `dd.MM.yyyy`, например `28.10.2026`.

## Требования

- Java 17 или новее;
- Apache Maven;
- зависимости Jackson для работы с JSON и датами;
- JUnit 5 для запуска тестов.

## Запуск проекта

1. Открой терминал в корневой папке проекта.

2. Убедись, что Java и Maven установлены:

   ```bash
   java -version
   mvn -version
   ```

3. Скомпилируй проект:

   ```bash
   mvn compile
   ```

4. Запусти приложение:

   ```bash
   mvn exec:java -Dexec.mainClass="com.example.Main"
   ```

Если Maven сообщает, что цель `exec:java` недоступна, добавь в `pom.xml` плагин `exec-maven-plugin` или запусти `com.example.Main` напрямую из своей IDE.

При первом запуске приложение создаст файл `tasks.json` в текущей рабочей папке, если этого файла ещё нет. Не удаляй его, если хочешь сохранить задачи.

## Команды приложения

| Команда | Назначение |
|---|---|
| `help` | Показать список команд |
| `add` | Создать задачу |
| `update` | Изменить существующую задачу по ID |
| `remove` | Удалить задачу по ID |
| `get_task` | Найти задачу по ID |
| `get_all` | Показать все задачи |
| `get_by_priority` | Отфильтровать задачи по приоритету |
| `get_by_status` | Отфильтровать задачи по статусу |
| `get_by_deadline` | Показать задачи со сроком до указанной даты включительно |
| `exit` | Завершить работу приложения |

## Запуск тестов

Запусти все тесты из корневой папки проекта:

```bash
mvn test
```

Чтобы запустить тесты через IDE, открой папку `src/test/java` и запусти нужный тестовый класс или все тесты проекта.

Тесты используют JUnit 5. Для тестов репозитория используется отдельный временный файл, чтобы не изменять основной `tasks.json`.
